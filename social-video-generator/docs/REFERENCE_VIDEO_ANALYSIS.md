# Análisis del vídeo de referencia

Revisión: 21 de octubre de 2026.

`references/reference-instagram.mp4` **no existe todavía** en este proyecto ni en `references/` de la web original. No es posible medir resolución, duración, FPS, cortes, ritmo, movimiento o composición sin el archivo. Por tanto, no se ha inferido ningún detalle del Reel.

Cuando se aporte, ejecutar `ffprobe` para duración, resolución y FPS; extraer fotogramas en intervalos representativos con FFmpeg y elaborar una hoja de contacto. Registrar la duración del hook, los cambios de escena, los elementos simultáneos, las zonas de texto y el uso de contadores. Solo se adaptarán principios generales de claridad y ritmo; nunca assets, vehículos, transiciones distintivas o identidad del creador.

El prototipo actual es independiente de esa referencia y puede revisarse después sin invalidar los datos ni el motor matemático.
